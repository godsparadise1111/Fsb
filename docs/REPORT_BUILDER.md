# گزارش‌ساز حرفه‌ای و پویا

## امکانات
صفحه /reports گزارش‌های مدیریتی و SLA قبلی را حفظ می‌کند و گزارش‌ساز پویا را نیز ارائه می‌دهد.

- منابع ثابت: سازمان‌ها، اعضای کل مشتری (فقط در حالت Tenant-wide و انتخاب همه سازمان‌ها)، فرم‌ها، پاسخ‌های فرم، نمونه‌های فرایند و وظایف گردش‌کار.
- فیلدهای سفارشی پاسخ‌ها: استخراج از Schema نسخه‌های منتشرشدهٔ فرم؛ هر فیلد به همان نسخه فرم محدود می‌شود تا فیلدهای هم‌نام فرم‌های دیگر با آن مخلوط نشوند. نوع متنی، عددی و تاریخی پشتیبانی می‌شود.
- فیلترهای امن، گروه‌بندی و تجمیع count/sum/avg/min/max.
- ذخیره، ویرایش، حذف و اشتراک گزارش در Tenant؛ گزارش اشتراکی برای سایر مدیران/کاربران مجاز فقط خواندنی است.
- خروجی CSV، Excel (XLSX) و PDF.
- Cache دیتابیسی با TTL شصت‌ثانیه‌ای و کلید تفکیک‌شده برای دامنه Tenant/سازمان.
- اجرای پس‌زمینه با صف دیتابیسی، lease، قفل SKIP LOCKED، retry و وضعیت‌های قابل پیگیری.
- زمان‌بندی روزانه، هفتگی و ماهانه (روز اول ماه) و ارسال فایل CSV گزارش به ایمیل مالک زمان‌بندی؛ اجرای عقب‌افتاده پس از خاموشی Worker به یک نوبت catch-up محدود می‌شود.

## کنترل دسترسی
- API به JWT، Tenant فعال و Feature Gate advanced_reports نیاز دارد.
- مجوز tenant.reports.read می‌تواند از عضویت Tenant Admin یا از نقش با دامنه ORGANIZATION و تخصیص صریح به همان سازمان به دست آید.
- در حالت سازمانی، انتخاب سازمان الزامی است و همه عملیات ذخیره، Job و زمان‌بندی دوباره با همان دامنه کنترل می‌شوند؛ تغییر شناسه سازمان در URL یا بدنه باعث گسترش دسترسی نمی‌شود.
- فهرست سازمان‌های قابل گزارش از تخصیص نقش و مجوزهای فعال DB ساخته می‌شود؛ organizationId ارسالی فقط درخواست محدوده است و Guard مالکیت آن را از DB کنترل می‌کند.
- گزارش سازمانی فقط به سازمان انتخاب‌شده محدود می‌شود. منبع اعضای مشتری فقط برای دسترسی Tenant-wide فعال است.
- Job فقط برای مالک آن قابل مشاهده است. زمان‌بندی نیز فقط برای مالک قابل مدیریت است و ایمیل فقط به نشانی حساب فعال همان مالک فرستاده می‌شود.
- گزارش‌های ذخیره‌شده و نتایج Cache/Job با tenantId و scope محدود می‌شوند.

## محدودیت‌های گزارش
- بازه زمانی حداکثر ۳۶۶ روز؛ حداکثر ۱۰ شرط؛ حداکثر ۵۰ مقدار در شرط in؛ حداکثر ۲۰۰ ردیف؛ timeout دیتابیس ده ثانیه.
- هیچ SQL، نام جدول یا عبارت فیلد از ورودی کاربر اجرا نمی‌شود. منابع/عبارات از Registry سمت سرور و مقادیر با پارامترهای SQL ساخته می‌شوند.
- CSV با BOM و خنثی‌سازی سلول‌های آغازشونده با =, +, -, @ تولید می‌شود.
- PDF به یک فونت TTF با پشتیبانی فارسی نیاز دارد. پیش‌فرض /usr/share/fonts/truetype/dejavu/DejaVuSans.ttf است؛ در صورت استفاده از فونت دیگر، FSB_PDF_FONT_PATH را تنظیم کنید.
- Cache بعد از ۶۰ ثانیه منقضی می‌شود و Worker ورودی‌های منقضی را به‌صورت batch پاک‌سازی می‌کند.

## API
تمام مسیرها زیر /api/tenant/report-builder قرار دارند.

| روش | مسیر | کارکرد |
|---|---|---|
| GET | /scope | تعیین دامنه Tenant-wide یا سازمانی و سازمان‌های قابل گزارش |
| GET | /organizations/accessible | سازمان‌های قابل گزارش برای کاربر |
| GET | /catalog?organizationId=... | منابع و فیلدهای مجاز، شامل Schema فرم |
| POST | /run | اجرای فوری گزارش |
| GET/POST | /saved | فهرست/ذخیره گزارش |
| GET/PATCH/DELETE | /saved/:id | مشاهده، ویرایش مالک و حذف مالک |
| GET | /saved/:id/run | اجرای گزارش ذخیره‌شده |
| GET | /saved/:id/export.csv | خروجی CSV |
| GET | /saved/:id/export.xlsx | خروجی Excel |
| GET | /saved/:id/export.pdf | خروجی PDF |
| POST | /jobs | ثبت اجرای پس‌زمینه |
| GET | /jobs/:id?organizationId=... | وضعیت و نتیجه Job (فقط مالک) |
| GET/POST | /schedules | فهرست/ساخت زمان‌بندی |
| PATCH | /schedules/:id/active | توقف یا فعال‌سازی زمان‌بندی |

## Workerها و تنظیمات
Workerها را به‌صورت process مستقل اجرا کنید؛ روی همه Replicaهای API متغیر فعال‌سازی را روشن نکنید:

- گزارش‌ها: npm run worker:reports --workspace @fsb/api با FSB_REPORT_WORKER_ENABLED=true.
- ایمیل: npm run worker:notifications --workspace @fsb/api با FSB_NOTIFICATION_WORKER_ENABLED=true و تنظیم SMTP.
- FSB_REPORT_POLL_MS بازه polling گزارش را تنظیم می‌کند (۱ تا ۶۰ ثانیه).
- FSB_OUTBOX_ENCRYPTION_KEY باید کلید ۳۲ بایتی hex یا base64 باشد؛ برای ساخت کلید hex: openssl rand -hex 32.
- FSB_PDF_FONT_PATH باید به فایل TTF فارسی موجود در محیط اجرای API اشاره کند.
- برای ایمیل، FSB_PUBLIC_APP_URL, FSB_SMTP_HOST, FSB_SMTP_PORT, FSB_EMAIL_FROM و در صورت نیاز FSB_SMTP_USER/FSB_SMTP_PASS لازم است.
